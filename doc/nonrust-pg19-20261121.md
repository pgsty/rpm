## 状态口径

- `not-tested`：尚未验证；不能据此认定支持或不支持。
- `regression-passed`：当前包已通过有效环境下的上游回归；`regression-reviewed-differences` 表示仅有已人工核对的排序/计划/文案差异，原始回归退出码仍保留。
- `regression-failed`：有效回归存在待解决差异，优先于简单安装冒烟状态。
- `built-pending-qa`：仅完成打包，尚未检查 payload/debug。
- `payload-passed`：包内容与 debug 已检查；运行兼容性仍待验证。
- `smoke-passed`：已安装实际包并完成独立 PG19 数据库冒烟；不代替上游完整回归。
- `functional-passed` / `partial-regression-passed`：仅通过所列功能或回归子集；具体未覆盖路径见 `regression_coverage`。
- `not-applicable`：基础库/服务没有 PostgreSQL ABI 维度；实际构建结果另见 `pilot_builds`，不能把此状态理解为未构建。
- `vendor-package-available`：指定坐标复用供应商包；`upstream-unsupported`、`heavy-deferred` 等表示已明确处置的暂缓项。
- `build-failed` / `dependency-failed` / `spec-rejected`：保留当前首个真实错误，未被当作成功。
- 含 `overlay` 的记录是隔离容器内的 PG19 候选配方；成功后仍须合入本地配方。失败的 PG19 候选不会直接加入正式支持范围。

- Citus 14.3.0 的 configure 明确拒绝 PG19；AGE 的 PG18 归档在 index_beginscan API 上失败，继续保留原支持范围。
- QDGC 仍采用 PGXN 0.1.0；GitHub v1.0.0 是 2021 年旧网格生成器，不是扩展的新版本。
- supautils 升为 4.0.1、sslutils 升为 1.4.2；两侧 PG19 已通过主包/debug 检查和安装冒烟。QDGC 为纯 SQL，不生成 debug 子包。
- sslutils 1.4.2 安装上游 SQL 与权限模型；旧 1.4.1 定制补丁不再应用，旧补丁文件和历史条目保留。未补写上游缺失的升级 SQL。
- Ubuntu postgresql-common 的默认列表仍到 18；通过官方支持的 `PG_SUPPORTED_VERSIONS=19` 显式选择。
- EL9 PGXS 固定 LLVM21 路径但系统 clang/LLVM 为 22；候选/修订配方使用匹配的 `/usr/bin` 工具目录，LLVM 始终开启。
- aggs_for_vecs：PG19 将 numeric_*_opt_error 替换为 numeric_*_safe；所有调用的错误参数均为 NULL，用 PG_VERSION_NUM 条件适配并保留旧版本路径。
- codesystem：旧 `-std=c99` 与 PG19 头文件 static_assert 不兼容，改为 gnu11；尚无本地 DEB recipe。
